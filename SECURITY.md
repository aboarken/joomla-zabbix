# Security policy

## Supported versions

Only the latest release of `com_zabbix` gets security fixes. Joomla sites update through
**System → Update → Extensions**.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately on GitHub: **Security** tab →
**Report a vulnerability**. Include the version, what an attacker can do, and the steps to
reproduce it.

You will get an answer within a few working days. A confirmed vulnerability is fixed in a new
release, and the advisory is published once sites can update.

## Scope

- The component's code: backend views, the portal pages, the data requests and the release
  workflow.
- Out of scope: Zabbix and Joomla themselves (report those to their projects), and settings an
  administrator chose (for example TLS verification switched off).
